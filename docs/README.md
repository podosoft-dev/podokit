# PodoKit documentation

PodoKit v1 generates Bun 1.4.0 applications with an Elysia API and SvelteKit web
app. The CLI can run under Node or Bun; the application uses Bun.

## Start a project

1. [Getting Started](getting-started.md) — choose a template and infrastructure,
   create a project, add features, and run or validate it.
2. [Templates](templates.md) — compare `fullstack`, `todo`, and `base` and inspect
   the generated structure.
3. [Runtime providers](providers.md) — database, cache, storage, events, and job
   choices, defaults, settings, persistence, and provider switching.
4. [Modules](modules.md) — feature installation, capability dependencies,
   configuration, and API endpoints.

For a small tool or single-process app, start with
[SQLite, memory cache/events, local files, and local jobs](getting-started.md#small-app-with-local-providers).
The default server choices are PostgreSQL, Redis, S3, Redis events, and BullMQ.

## Compatibility and contributing

PodoKit v1 does not automatically convert Node/NestJS projects generated by
PodoKit 0.x. Keep those projects on `@podosoft/podokit@0.17.4` or deliberately
migrate application behavior into a new v1 project. See [Updating](updating.md).
