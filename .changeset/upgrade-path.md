Fix the upgrade path to 1.2 and add three admin and streaming limits. `podo update` adds the module for the selected provider when a module gains a capability requirement (such as `sse` requiring `events`), lists it under "Modules to add", and moves a provider recorded after its dependents in front of them; `podo add` places a new provider ahead of the installed modules that need it. Template ranges for PodoKit packages name the current versions, so updated apps get `@podosoft/podokit-api-client` 0.8.5. `admin:bootstrap` loads a bundled runtime entry, works on PostgreSQL and SQLite, and reports why it cannot connect. The audit filter and new admin session list indexes build concurrently on PostgreSQL, with TypeORM migrations running one transaction each. On SQLite the auth configuration reports `enabled` as a boolean and a new session idle timeout applies without a syntax error. `SSE_MAX_STREAMS_PER_USER` caps a user's event streams per API replica (429 `EVENTS_STREAM_LIMIT`). `GET /admin/users` lists users with combined role and status filters, and the admin users page uses it. Several generated UI specs wait for hydration or read responses before navigating on, and the generated specs pass strict type checking.
